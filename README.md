# Expense Tracker

A responsive Expense Tracker built with HTML and CSS to practice frontend development and clean code. The `main` branch contains the refactored version, while the `messy_code` branch keeps the original AI-generated version for comparison.

Added User Signup and Login functionality with local storage authentication.
Implemented Logout feature for secure session management.
Improved the overall user authentication flow and user experience.

**Tech Stack:** HTML5 • CSS3 • Git • GitHub
